## 1. What Changed From the Placeholder Catalog

The previous course-content document (v1.0) used illustrative sample courses to unblock the website build before real content existed. This version replaces it entirely with the institute's actual 2026 marketing course catalog — **37 courses across 15 categories**, transcribed field-for-field from the supplied spreadsheet. Nothing here is invented; taglines, skills, tools, portfolio projects, and career outcomes all come directly from the source file.

**Two things from the source file are flagged, not silently accepted:**
- The spreadsheet's own notes state that **Industry Certification** values (Microsoft, Google, Meta, Adobe, Cisco, AWS, Autodesk, etc.) are *illustrative pathway names* — confirm which, if any, are real certification/exam partnerships before publishing these as claims on the live site. An unverified "Google Certified" or "Meta Certified" claim is a legal and reputational risk.
- **Institute Certificate** tiers (Certificate / Professional Certificate / Diploma / Advanced Diploma / Career Program) are used as given — confirm these match how Darbar Computer actually names its own credentials.

## 4. Field Reference — Updated `Course` Type

The original `Course` type in the website build document needs a few additions to hold this richer marketing content. Updated shape:

```typescript
export interface Course {
  id: string;
  slug: string;
  title: string;
  category: string;
  tagline: string;                 // NEW — short marketing hook, shown on cards
  level: "Beginner" | "Intermediate" | "Advanced" | "Beginner to Intermediate";
  duration: string;                // e.g. "8 Weeks" — kept as display string per source data
  learningMode: string;            // e.g. "Physical / Online / Hybrid"
  newBatch: string;                // e.g. "Every Week", "Every Sunday"
  timing: string;                  // e.g. "Morning / Day / Evening"
  instituteCertificate: string;    // e.g. "Certificate", "Diploma", "Professional Certificate"
  industryCertification?: string;  // e.g. "Microsoft", "Google, Meta" — "—" means none; confirm before publishing as a claim
  internship?: string;             // e.g. "Optional Internship", "Internship Available"
  targetStudents: string;
  shortDescription: string;        // maps to "One-Line Description"
  skillsGained: string[];
  softwareTools: string[];
  portfolioProjects: string[];
  careerOpportunities: string[];
  image: string;
  featured?: boolean;
  // feeNPR intentionally omitted — add once real pricing is approved
}
```

Semicolon-separated source fields (Skills Gained, Software & Tools, Portfolio Projects, Career Opportunities) should be split into arrays (`.split(';').map(s => s.trim())`) when transcribing into `courses.ts`, so the frontend can render them as tag lists/bullet points rather than one long string.
